# Tawan Impex Frontend

Bulk sportswear brand website for Tawan Impex built with modern full-stack technologies, showcasing products, brand identity, and scalable B2B e-commerce structure.

## Tech Stack

- **React** + **Vite** for fast development
- **TailwindCSS** for styling
- **React Router** for navigation

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment Variables

Create a `.env` file with:

```
VITE_API_URL=http://localhost:5000/api
```

## Deployment

The frontend is configured for Vercel deployment.
